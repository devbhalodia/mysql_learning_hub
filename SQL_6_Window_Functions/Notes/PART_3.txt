1. PERCENTILE_DISC :- finding median (or item value at any percentile). 
q1) find the median marks of students:- 
SELECT *,
PERCENTILE_DISC(0.5) WITHIN GROUP(ORDER BY marks) OVER() AS 'median_marks' 
FROM marks

in the percentile_disc func, we mention the percentile. as it was median, we wanted 50th percentile. 
because before median computation, we need to have our data sorted and that is done by within group where specified column gets sorted. 

q2) find branchwise median marks:- 
SELECT *,
PERCENTILE_DISC(0.5) WITHIN GROUP(ORDER BY marks) OVER(PARTITION BY branch) AS 'median_marks' 
FROM marks

-------------------------------------------------------------------------

2. PERCENTILE_CONT :-
it is just like percentile_disc, but here, it may return values which aren't in dataset. 
for:- 
1,2,3,4,4,5
---> if percentile_cont(0.5) used:-
we get ans = 3.5 which is not in the dataset.

---> if percentile_disc(0.5) used:-
we get ans = 3 or 4 which is inside the dataset. 

percentile_cont is mainly used for major part of calculations. 

q) detect and remove outliers.
SELECT * FROM (SELECT *,
PERCENTILE_CONT(0.25) WITHIN GROUP(ORDER BY marks) OVER() AS 'Q1',
PERCENTILE_CONT(0.75) WITHIN GROUP(ORDER BY marks) OVER() AS 'Q3'
FROM marks) t
WHERE t.marks <= t.Q1 - (1.5*(t.Q3 - t.Q1));

here, all values below the min value, removed.

3. SEGMENTATION:- 
divides the data into exactly specified number of parts based on the condition. 
q) divide the dataset into 3 parts based on marks of the students. 
SELECT *, 
NTILE(3) OVER (ORDER BY marks DESC) as 'buckets'
FROM marks

real world application question:- 
divide the smartphones into 3 categories:- budget, mid-range, and premium:- 

SELECT brand__name, model, price,
CASE 
  WHEN bucket = 1 THEN 'budget'
  WHEN bucket = 2 THEN 'mid-range'
  WHEN bucket = 3 THEN 'premium'
FROM (SELECT brand_name, model, price, 
NTILE(3) OVER (ORDER BY price) AS 'bucket' 
FROM smartphones) t
