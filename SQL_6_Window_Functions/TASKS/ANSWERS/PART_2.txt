7.
SELECT `Type`, AVG(EaseOfUse), AVG(Satisfaction) FROM (SELECT * FROM (SELECT *,
ROW_NUMBER() OVER(PARTITION BY `Type` ORDER BY Price ASC) AS 'rn',
COUNT(*) OVER(PARTITION BY `Type`) AS 'total_rows'
FROM drug) t
WHERE t.rn > (t.total_rows/2)) f
GROUP BY f.`Type`;

so, in this question:-
we want to compute the avg of ease of use and satisfaction for each type, but ONLY for prices > median prices for each type. 

step 1:- 
for each type, calculate the median prices. for that, we use row_number which gives a unique number to each row ordered by price. this is done so that we get total rows in each group and then with those total rows, we can find out median being total_rows/2 and then we can select all those rows where the row_number is greater than median value so that we can have the prices > median prices. 
SELECT *,
ROW_NUMBER() OVER(PARTITION BY `Type` ORDER BY Price ASC) AS 'rn',
COUNT(*) OVER(PARTITION BY `Type`) AS 'total_rows'
FROM drug

step 2:- 
SELECT * FROM (SELECT *,
ROW_NUMBER() OVER(PARTITION BY `Type` ORDER BY Price ASC) AS 'rn',
COUNT(*) OVER(PARTITION BY `Type`) AS 'total_rows'
FROM drug) t
WHERE t.rn > (t.total_rows/2)

step 3:- 
finally computing the avg. 
SELECT `Type`, AVG(EaseOfUse), AVG(Satisfaction) FROM (SELECT * FROM (SELECT *,
ROW_NUMBER() OVER(PARTITION BY `Type` ORDER BY Price ASC) AS 'rn',
COUNT(*) OVER(PARTITION BY `Type`) AS 'total_rows'
FROM drug) t
WHERE t.rn > (t.total_rows/2)) f
GROUP BY f.`Type`;

9. 
SELECT `Condition`, Satisfaction AS 'median_sat' FROM (SELECT *,
ROW_NUMBER () OVER(PARTITION BY `Condition` ORDER BY Satisfaction) AS 'rn',
COUNT(*) OVER(PARTITION BY `Condition`) AS 'total_rows'
FROM drug) t
WHERE rn = (total_rows)/2
ORDER BY median_sat DESC;
